## 🧾 Sobre o Projeto

Este é o meu site pessoal, desenvolvido para apresentar informações sobre mim, meus projetos e formas de contato. O site é construído utilizando HTML e CSS puros, com foco em simplicidade e responsividade.

## 🚀 Tecnologias Utilizadas

- **HTML5** – Estrutura do site
- **CSS3** – Estilização e layout
- **BOOTSTRAP** Layout responsivo e estilização fácil e prática

## 📂 Estrutura do Projeto

```bash
Meu-Site-Pessoal/
├── assets/             # Imagens e recursos visuais
│   └── img/            # Imagens utilizadas no site
├── index.html          # Página principal do site
└── README.md           # Documentação do projeto
```
