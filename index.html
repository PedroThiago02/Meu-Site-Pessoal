Minhas Habilidades

Ao decorrer de minha carreira na área de T.I, desenvolvi algumas habilidades dentro do curso Técnico em informática na EEEP Dr. Napoleão Neves da Luz, dentre eles estão:

Linguagens de Programação:

JavaScript

Sou desenvolvedor com habilidades em JavaScript, uma linguagem versátil e essencial para o desenvolvimento web. Tenho experiência na criação de interfaces interativas, manipulação de DOM, e uso de frameworks modernos como Node.js para aplicações front-end e back-end. Com JavaScript, posso desenvolver desde sites dinâmicos e responsivos até APIs, sistemas interativos, dashboards e aplicações em tempo real.

PHP

Tenho experiência com PHP, uma linguagem amplamente utilizada no desenvolvimento web back-end. Com PHP, sou capaz de criar sistemas dinâmicos, como portais, blogs, e-commerces, sistemas de login/autenticação, além de desenvolver e consumir APIs. Conheço o uso de bancos de dados relacionais como MySQL, integração com formulários, sessões e cookies, e também frameworks como Laravel, que agilizam e organizam o desenvolvimento de aplicações robustas e seguras.

Delphi

Possuo experiência com Delphi, uma linguagem voltada ao desenvolvimento de aplicações desktop com interface gráfica para Windows. Utilizo Delphi para criar sistemas corporativos, controle de estoque, gestão de vendas, entre outros, com foco em performance e usabilidade. Tenho conhecimento na manipulação de bancos de dados (como MySQL, SQL Server), e uso de componentes visuais para acelerar o desenvolvimento. Delphi é uma ótima ferramenta para sistemas robustos e estáveis em ambiente local.

Frameworks:

Laravel

Tenho experiência com Laravel, um dos frameworks PHP mais populares e poderosos para o desenvolvimento web moderno. Utilizo Laravel para criar sistemas escaláveis, seguros e bem estruturados, como painéis administrativos, e-commerces, APIs e sistemas de gestão personalizados. Domino recursos como migrations, autenticação, validações, middlewares e integração com serviços externos. Com sua arquitetura limpa e suporte a boas práticas, Laravel me permite entregar aplicações eficientes e de fácil manutenção.

Bootstrap

Tenho domínio de Bootstrap, um dos frameworks CSS mais utilizados para o desenvolvimento de interfaces web modernas e responsivas. Com ele, consigo criar layouts adaptáveis para diferentes dispositivos, utilizando sua grade flexível, componentes prontos e utilitários de estilização. Uso Bootstrap para agilizar o desenvolvimento front-end de painéis administrativos, landing pages, formulários, e-commerces e muito mais, garantindo um visual limpo, padronizado e com boa usabilidade.

Ferramentas e Tecnologias:

Git

Tenho experiência com Git, ferramenta essencial para o controle de versionamento de código. Utilizo Git em projetos individuais e em equipe para gerenciar versões, trabalhar com branches, realizar merge, resolver conflitos e manter um histórico claro e organizado do desenvolvimento. Tenho familiaridade com plataformas como GitHub, GitLab e Bitbucket, onde colaboro em repositórios, faço pull requests, code reviews e acompanho o fluxo de desenvolvimento com práticas como Git Flow.

VS Code

Utilizo o Visual Studio Code (VS Code) como meu principal ambiente de desenvolvimento. Com ele, trabalho de forma produtiva em projetos front-end e back-end, aproveitando recursos como extensões personalizadas, IntelliSense, depuração, terminal integrado e controle de versionamento com Git. Conheço atalhos, temas e ferramentas que otimizam meu fluxo de trabalho, além de integrar o VS Code com tecnologias como JavaScript, PHP, Laravel, HTML/CSS, Bootstrap e bancos de dados. É uma ferramenta essencial no meu dia a dia como desenvolvedor.

MySQL

Tenho experiência com MySQL, um dos sistemas de gerenciamento de bancos de dados relacionais mais utilizados no mercado. Utilizo MySQL para modelar, criar e gerenciar bases de dados, escrevendo queries otimizadas, stored procedures, triggers e views. Tenho prática em realizar joins complexos, normalização de dados, e integração com linguagens como PHP (Laravel), JavaScript e Delphi. Também uso ferramentas como phpMyAdmin, MySQL Workbench ou DBeaver para facilitar a administração e análise de dados.

AWS

Tenho conhecimentos em AWS (Amazon Web Services), plataforma de serviços em nuvem que utilizo para hospedar, escalar e gerenciar aplicações web. Já trabalhei com serviços como EC2 (servidores virtuais), S3 (armazenamento de arquivos), RDS (banco de dados gerenciado), Route 53 (DNS), e CloudWatch (monitoramento). Utilizo AWS para garantir alta disponibilidade, escalabilidade e segurança, seja em ambientes de produção, testes ou desenvolvimento. Também tenho familiaridade com boas práticas de backup e gerenciamento de permissões via IAM.

WordPress

Tenho experiência com WordPress, a plataforma mais popular para criação de sites e blogs. Desenvolvo e personalizo temas e plugins, além de configurar e manter sites otimizados e seguros. Utilizo WordPress para criar portfólios, e-commerces (com WooCommerce), landing pages, blogs corporativos e institucionais, com foco em performance, SEO e responsividade. Tenho conhecimento tanto no uso do painel administrativo quanto no desenvolvimento mais técnico com PHP, HTML, CSS e JavaScript para customizações avançadas.

Figma

Tenho conhecimento em Figma, uma das principais ferramentas de design de interfaces e prototipação. Utilizo Figma para criar layouts modernos, responsivos e intuitivos, além de colaborar com equipes de design e desenvolvimento em tempo real. Tenho experiência em wireframes, protótipos navegáveis, sistemas de design, e exportação de assets para projetos web e mobile. Figma é uma ferramenta essencial no meu fluxo de trabalho para alinhar estética, usabilidade e funcionalidade antes do desenvolvimento.

Sobre Mim

Saiba mais sobre minha história

Me chamo Pedro Thiago e irei contar sobre minha trajetória pessoal e acadêmica

Desde muito jovem, fui cercado por uma base familiar sólida e afetuosa. Fui criado por uma família extremamente amorosa, juntamente com dois irmãos que sempre demonstraram atenção, cuidado e, sobretudo, um grande incentivo à minha formação. Desde os primeiros anos de vida, fui orientado a valorizar a educação como ferramenta essencial de transformação e crescimento. Iniciei minha vida escolar com apenas um ano de idade. Ao longo dessa jornada, construí diversas amizades e experiências que, ainda que nem todas estejam vivas em minha memória, foram fundamentais para meu desenvolvimento pessoal e social. Venho de uma família brasileira de classe média baixa, onde sempre ficou muito claro que a educação seria o caminho mais seguro e digno para melhorar de vida. Desde os primeiros anos escolares, demonstrei afinidade com os estudos — especialmente com a matemática — e, inspirado por minha mãe, que é técnica em enfermagem, sonhei durante muito tempo em seguir carreira na área da saúde. Ela sempre foi minha maior referência e fonte de motivação, transmitindo valores fundamentais como dedicação, foco e trabalho árduo. A ela, sou eternamente grato.

Placeholder

Durante minha adolescência, como muitos jovens, passei por diferentes fases de autodescoberta. Cogitei ser dentista, policial ou bombeiro, mas foi apenas por volta dos 15 anos, já no ensino médio, que descobri minha verdadeira vocação: a tecnologia. Meu interesse por programação surgiu de forma natural, encantado com o mundo do desenvolvimento de sistemas, criação de softwares, APIs e sites. Desde criança, sempre tive acesso ao computador e certa familiaridade com tecnologia, mas foi nesse momento que comecei, de fato, a compreender como tudo funcionava. O fascínio por entender a lógica por trás dos sistemas me envolveu de forma profunda. Trabalhar com aquilo que gosto — utilizando o computador para criar soluções — tornou-se meu grande objetivo de vida. Apesar das dificuldades — como quando meu antigo computador queimou — recebi o apoio de professores incríveis, em especial uma professora que me emprestou seu próprio notebook para que eu não parasse de estudar. São gestos assim que marcam uma vida e solidificam ainda mais a certeza do caminho escolhido. A paixão pela programação cresceu a cada projeto, cada código, cada pequeno avanço. Atualmente, estou cursando o 3º ano do Ensino Médio na Escola Estadual de Educação Profissional Dr. Napoleão Neves da Luz, na formação de Técnico em Informática. Meu próximo grande passo é ingressar na Universidade Federal do Cariri (UFCA), no curso de Engenharia de Software — onde pretendo aprofundar meus conhecimentos e expandir ainda mais minhas habilidades técnicas e humanas. Agradeço sinceramente pelo interesse em conhecer um pouco mais da minha história.
